# 提示词卫生

核心原则：

> 任何送进 LLM 的文本，**当作会永久留存 + 可能被调取 + 可能进入训练 + 可能被人工审核**。

配套脚本：`scripts/redact.sh`（脱敏）、`scripts/check-prompt.sh`（检查）、`hooks/prompt-guard.py`（自动拦截）。

---

## 1. 发送前检查表

逐条过。命中任一条就处理，不要"应该没事"。

```
【身份】
□ 真实姓名 / 昵称 / 拼音 / 首字母缩写 / 网名
□ 年龄 / 生日 / 星座 → 组合可缩小范围
□ 身份证号 / 护照号 / 驾照号 / 社保号

【联系方式】
□ 手机号（含中间打码的，某几位可反推）
□ 邮箱（含工作邮箱 → 直接暴露公司）
□ 微信 / QQ / Telegram / Discord / 其他 IM 账号
□ 社交平台用户名（跨平台复用 ⇒ 关联）

【地理】
□ 家庭住址 / 公司地址
□ 精确到市/区/街道/门牌号的来源地
□ 常去地点 / 通勤路线

【职业】
□ 学校 / 专业 / 班级 / 学号
□ 公司 / 部门 / 职级 / 工号
□ 项目代号 / 客户名 / 未公开产品名
□ 面试/求职状态 / 目标公司

【设备】
□ 车牌号 / 设备序列号 / MAC / IMEI / 主机名
□ 硬件配置（组合可指纹）
□ 软件版本（组合可指纹）

【财务】
□ 银行/支付账号 / 钱包地址
□ 订单号 / 交易哈希

【第三方】（法律风险最高）
□ 客户 / 同事 / 家人 / 朋友的任何个人信息
□ 未成年人信息（额外法律义务）

【内部资产】
□ 内网 IP / 主机名 / 域名 / 服务名
□ 数据库连接串 / 内部 API 地址
□ 凭据 / token / 私钥

【行为指纹】
□ 唯一措辞习惯 / 口头禅 / 特殊错别字模式
□ 特殊标点习惯（如固定用全角/半角）
□ 独特的排版/注释风格
```

## 2. 脱敏流水线

```bash
# 单次使用
cat app.log | ./scripts/redact.sh > app.clean.log

# 或定义成函数日常用
redact() { "$HOME/ai-opsec-privacy/scripts/redact.sh"; }
cat app.log | redact | pbcopy      # macOS
cat app.log | redact | xclip -sel c  # Linux
```

覆盖的规则：

| 类别 | 规则 |
|---|---|
| 路径用户名 | `/home/USER` `/Users/USER` `C:\Users\USER` |
| 内网 IP | `10.x` `172.16-31.x` `192.168.x` → `10.0.0.0` |
| 邮箱 | → `EMAIL@REDACTED` |
| 中国手机号 | `1[3-9]xxxxxxxxx` → `PHONE_REDACTED` |
| 身份证号 | 18 位 → `IDNUM_REDACTED` |
| API key | `sk-` `ghp_` `AKIA` `AIza` `xox?` `glpat-` `hf_` |
| 键值密钥 | `password=...` `token:...` `Bearer ...` |
| 内部主机名 | `*.internal` `*.local` `*.corp` |
| PEM 私钥 | 整块 → 占位符 |

**注意**：正则脱敏是启发式，**不覆盖**姓名、学校、公司、措辞习惯。这些必须人工处理。

## 3. 需要贴代码/日志时的替代做法

能不贴就不贴。必须贴时：

```bash
# 1) 只贴最小片段，不贴整个文件
sed -n '120,140p' app.log | redact

# 2) 用最小可复现示例替代真实数据
#    把真实值换成同结构的假值：
#    user_id=84213   →  user_id=12345
#    api.example.com →  api.foo.com

# 3) 保留结构，替换内容
#    JSON 用 jq 重建
jq 'walk(if type=="string" then "REDACTED" else . end)' data.json   # 粗暴全替
#    或按字段
jq 'map({id, status, .msg="REDACTED"})' data.json

# 4) 报错信息：去掉绝对路径和主机名
some-cmd 2>&1 | sed -E 's#(/[a-zA-Z0-9_.-]+)+/([a-zA-Z0-9_.-]+)#…/\2#g; s/\b[a-z0-9.-]+\.(com|net|org|io)\b/DOMAIN/g'
```

## 4. 假身份（需要人设时）

**不要在现场即兴编** —— 即兴编的会掺真信息（真实年龄段、熟悉的城市、真实的行业背景）。

预造，写死在文件里：

```
# ~/.ai-pseudo

PSEUDO_NAME=          # 与真名零字符/语义关联
PSEUDO_AGE=           # 不要用真实年龄段
PSEUDO_LOCATION=      # 大区域，不精确到街道
PSEUDO_OCCUPATION=    # 与真实职业无关
PSEUDO_EDUCATION=     # 预造，别留空让模型追问
PSEUDO_CONTACT=       # 一次性邮箱
PSEUDO_TZ=            # 时区与 location 一致
```

用法：

```bash
source ~/.ai-pseudo
cat <<EOF | ./scripts/check-prompt.sh
帮我写一段自我介绍：
我是 $PSEUDO_NAME，$PSEUDO_AGE 岁，目前在 $PSEUDO_LOCATION，
从事 $PSEUDO_OCCUPATION。
EOF
```

**铁律**
```
· 每次用同一套（或按项目分套），不要随机化到自相矛盾
· 假身份的教育/工作背景也要预造完整
· 假身份的时区/语言与声称的 location 一致
· 不同项目用不同假身份（避免跨项目关联）
```

## 5. 绝不要在会话里做的事

```
× 问销赃 / 交易渠道 / 洗钱路径
    动机直接坐实，且永久留存

× 把真实凭据贴进去"帮我看看有什么问题"
    换成脱敏后的同结构样本

× 描述"只有你知道"的事件细节
    与真身强绑定，可反查

× 用真名"扮演自己"做角色扮演
    直接自曝

× 让 AI 生成含真实身份的简历 / CV / 档案 / 个人简介
    韩国银行案的破点就是这个

× 同一会话里先聊私事再聊敏感任务
    上下文关联，模型和服务端都能看到

× 在同一账号下跨项目复用对话
    服务端按账号聚合

× "换个说法问同一件事"
    语义等价会被聚类，问题本身不能问就是不能问
```

## 6. 上下文污染

**同一会话里**：先聊的内容会进入后续所有轮次的上下文。所以敏感任务要**开新会话**。

```
会话 A:  聊了家庭情况、工作、位置
会话 B:  在 A 之后继续 → 模型上下文里已有 A 的信息
```

**跨会话**：
- memory 开启时，A 里写的内容会进 B 的加载上下文
- 服务端即使关了 memory，仍可能按账号聚合

**对策**
```
□ 敏感任务开新会话
□ 关 memory / 个性化 / 从历史学习
□ 不同项目用不同账号（彻底隔离上下文）
□ 高敏不用同一账号（服务端聚合无法从客户端控制）
```

## 7. 语言与时区指纹

你控制不了的事：**你怎么说话本身就是指纹**。

```
易暴露的：
· 中文提示词 → 直接指向中文使用者
· 特定术语的选择（大陆/台湾/香港用词不同）
· 简繁混用、code-switch 模式
· 时区（活跃时段）
· 日期格式（YYYY-MM-DD vs DD/MM/YYYY）
· 计量单位（公里 vs 英里）
· 货币符号

对策：
□ 敏感任务提示词用英文
□ 报告/产出物 locale 设 en-US
□ 时区/语言/单位与你要"看起来像"的地方一致
□ 不 code-switch（台湾政府案就是被这个指认的）
```

## 8. 发送前快速自检

```bash
# 一条命令走完检查
echo "$PROMPT" | ./scripts/check-prompt.sh

# 装 hook 后自动拦截（见 hooks/）
```

退出码非零就处理，不要强行发送。

## 9. 常见误区

| 以为 | 实际 |
|---|---|
| 我打码了手机号中间几位 | 前 7 位 + 后 2 位足以缩小到极小范围 |
| 我说了"我朋友"，不是"我" | 事件细节仍可指向你，且模型可能追问 |
| 我删了这条消息 | 服务端留存 + 你的 history.jsonl 仍有 |
| 我用小号问 | 同 IP/同设备/同支付方式仍可关联 |
| 我只贴了报错 | 报错常含绝对路径（带用户名）、主机名、内网 IP |
| 我换成英文问 | 用词习惯/时区仍在 |
| 我把 key 换成 xxx | 上下文常能反推真实 key 的形态，且展示"我见过 key"本身是信号 |

## 10. 检查清单

```
□ 脱敏检查表逐条过
□ 假身份模板已预造
□ 贴代码/日志前跑过 redact()
□ 敏感任务开了新会话
□ memory / 个性化已关
□ 没在会话里问销赃 / 贴凭据 / 生成真实身份文档
□ 没有先聊私事后聊敏感任务
□ 语言/时区与声称身份一致
□ 没做 code-switch
□ hook 已装，自动拦截生效
```
